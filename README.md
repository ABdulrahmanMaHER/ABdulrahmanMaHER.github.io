# Abdulrahman Maher | Odoo Developer Portfolio

Static portfolio (HTML, CSS, vanilla JS) styled after the Odoo backend: purple `#714B67`, teal `#017E84`, light and dark themes.

## Publish on GitHub Pages

1. On GitHub, create a **public** repo named exactly `ABdulrahmanMaHER.github.io` (no README, no .gitignore).
2. In this folder run:

```bash
git init -b main
git add .
git commit -m "Add portfolio site"
git remote add origin https://github.com/ABdulrahmanMaHER/ABdulrahmanMaHER.github.io.git
git push -u origin main
```

3. In the repo go to Settings > Pages, set Source to "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.
4. After about a minute the site is live at https://abdulrahmanmaher.github.io

## Editing
All content is in `index.html`. Colors are the CSS variables at the top of the `<style>` block.
